# My SoundPad (Free Edition)

Мой собственный саундпад, написанный на Python. 
Создан для личного использования, стримов и общения в Discord/Steam. 
Без подписок, скрытых платежей и телеметрии.

## 🚀 Возможности
- **20+ настраиваемых кнопок** со звуками.
- **Горячие клавиши:** назначение на любые клавиши (F1-F12, NumPad, буквы).
- **Виртуальный микрофон:** интеграция с VB-Audio Cable для передачи звука в Discord.
- **Управление:** пауза, стоп, громкость.
- **Сохранение профиля:** все звуки и бинды сохраняются в `soundpad_config.json`.
- **Темный дизайн:** приятный интерфейс, не бьющий по глазам.
